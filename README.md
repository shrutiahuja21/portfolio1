# Shruti Ahuja's AI Portfolio

This is a premium, state-of-the-art portfolio built with **React**, **Vite**, and **Framer Motion**.

## 🚀 How to Run Locally

1.  **Install Dependencies**:
    ```bash
    npm install
    ```
2.  **Start Development Server**:
    ```bash
    npm run dev
    ```
3.  **Build for Production**:
    ```bash
    npm run build
    ```

## ✨ Features
- **GenAI Showcase**: Highlights your work with LLMs, RAG, and LangChain.
- **Micro-Animations**: Powered by Framer Motion for a premium feel.
- **Glassmorphism Design**: Sleek dark mode with glowing accents.
- **Responsive Navigation**: Works perfectly on mobile and desktop.

## 🛠 Tech Stack
- **Frontend**: React, Vite
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Custom Design System)
